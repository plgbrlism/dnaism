# paul-research

one-line goal: findings in a table with source links.

| claim | source | date |
|---|---|---|
| short finding | link | yyyy-mm-dd |

| rule | detail |
|---|---|
| format | table with a source link per row |
| top | one-line answer first |
| sources | primary and official over aggregators |
| conflicts | add a row noting the disagreement |
| prose | none beyond the answer line |
| unknowns | say not found, never fill gaps from memory |

# paul-workflow

one-line goal: ask first, change little, report in a table.

## task flow

| step | rule |
|---|---|
| start | ask clarifying questions before doing any work, batch them in one message |
| plan | only for multi-step work, as a short table |
| work | smallest diff that solves it |
| end | table of what changed (file, change) |

## git

| item | rule |
|---|---|
| commit message | short lowercase phrase, no period, no prefix unless the repo uses one |
| commit size | one logical change |
| branch names | kebab-case |
| repo convention | wins over these defaults |

## pr

- one-line summary, then a table of changes
- no essays

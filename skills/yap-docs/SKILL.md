# yap-docs

one-line goal: docs small enough that someone actually reads them.

| rule | detail |
|---|---|
| top | one-line summary first |
| format | tables over prose and long bullets |
| length | space is limited on purpose, cut anything that is not needed |
| code | snippets only when needed |
| prose | no intro, no outro, no recap |
| filler | no generic sections like overview, introduction, conclusion |
| punctuation | no em-dashes, ever |
| names | kebab-case filenames |

## shape

| section | when |
|---|---|
| summary line | always |
| table | any list of 2+ items |
| snippet | only if the table cannot say it |
